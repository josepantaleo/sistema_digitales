Guía de Instalación para Windows


🙂‍↔️ Temas Anteriores

1. Obtener el archivo

Entra en la web oficial: code.visualstudio.com.

Haz clic en el botón azul "Download for Windows". Se descargará el instalador (ej. VSCodeUserSetup-x64.exe).

2. Ejecución y Configuración (Paso Crítico)

Inicia el instalador. Durante el proceso, presta atención a la Selección de tareas adicionales. Es fundamental marcar todas las casillas:

  • [x] Crear un acceso directo en el escritorio.
  • [x] Agregar la acción "Abrir con Code" al menú contextual de archivos.
  • [x] Registrar Code como editor para tipos de archivo admitidos.

Finalmente, haz clic en Instalar y luego en Finalizar.

Configuración y Extensiones Web (HTML & CSS)

Ajustes esenciales para trabajar con diseño web de forma eficiente.

1. El "Auto-Guardado"

Para no perder cambios ni olvidar guardar manualmente:

  • Ve a Archivo > Autoguardado.

Productividad Visual

Busca en extensiones (Ctrl + Shift + X):

  • Live Server: Actualización automática del navegador al guardar.
  • Color Highlight: Visualización de colores directamente en el código CSS.
  • CSS Peek: Acceso rápido a los estilos desde el archivo HTML usando Ctrl + Clic.

Escritura y Orden

  • Auto Rename Tag: Sincronización automática de etiquetas de apertura y cierre.
  • Prettier: Formateador automático de código (Shift + Alt + F).
  • IntelliSense for CSS: Autocompletado inteligente de clases CSS en HTML.

Consejo: Mantén instaladas solo las que ue ses para que VS Code siga siendo rápido.

Personalización: Idioma, Temas e Iconos

1. Cambiar el idioma a Español

  1. Busca en extensiones (Ctrl + Shift + X): "Spanish Language Pack".
  2. Instala y selecciona "Change Language and Restart" en el aviso emergente.

2. Temas y Estética

  • Colores: Presiona Ctrl + K + T para elegir un tema visual.
  • Iconos: Instala la extensión "Material Icon Theme" para identificar archivos visualmente.

ACTIVIDAD PRÁCTICA:
Modifique su Tarjeta Personal con HTML y CSS

OBJETIVO

Modificar y mejorar una tarjeta personal utilizando HTML5 y CSS3, aplicando diseño visual moderno, personalización y efectos interactivos.

CONSIGNA GENERAL

A partir del código entregado por el docente, el estudiante deberá crear una versión personalizada de la tarjeta digital. Se deberán modificar y mejorar los siguientes elementos:

  • Información personal
  • Imagen
  • Contenido

ACTIVIDADES

1) PERSONALIZACIÓN DE DATOS

Modificar la información del perfil cambiando:

  • Nombre y apellido
  • Profesión o rol
  • Ciudad
  • Institución
  • Intereses
  • Correo electrónico
  • Teléfono

El contenido debe ser coherente y estar correctamente escrito.

2) CAMBIO DE IMAGEN

Reemplazar la imagen por una personal o temática. Y esta debe debe:

  • Visualizarse correctamente
  • Mantener forma circular
  • No deformarse
  • Verse centrada

3) MODIFICAR COLORES

Personalizar el diseño modificando el color de fondo, colores del botón, colores de títulos/textos y colores de las tarjetas internas. Se recomienda utilizar colores pastel o armónicos:

background: lavender; background: skyblue; background: honeydew;

4) MEJORAR EL BOTÓN

Modificar el código <a href="#" class="boton">Contactar</a> para convertir el botón en un enlace funcional seleccionando una opción:

OPCIÓN A — Abrir correo electrónico

Utilizar mailto: para abrir la aplicación de correo.

<a href="mailto:correo@gmail.com" class="boton"> 📧 Contactar </a>
OPCIÓN B — Abrir WhatsApp

Utilizar wa.me para abrir un chat de WhatsApp.

<a href="https://wa.me/3544666666" class="boton"> 💬 Enviar WhatsApp </a>

Mejoras visuales del botón requeridas (CSS): Agregar ícono, efecto hover, animación y cambio de color al pasar el mouse. Ejemplo:

.boton{ display:inline-block; padding:12px 20px; background:skyblue; color:white; text-decoration:none; border-radius:30px; transition:0.3s; animation:aparecer 1s ease; } .boton:hover{ background:lightseagreen; transform:scale(1.05); } @keyframes aparecer{ from{ opacity:0; transform:translateY(20px); } to{ opacity:1; transform:translateY(0); } }

5) AGREGAR UNA NUEVA SECCIÓN

Crear una nueva sección llamada “Habilidades” que contenga una lista de conocimientos o tecnologías (HTML5, CSS3, JavaScript, Diseño Web, GitHub):

<section class="habilidades"> <h2>Habilidades</h2> <ul> <li>HTML5</li> <li>CSS3</li> <li>JavaScript</li> </ul> </section>

6) AGREGA SECCIÓN REDES SOCIALES

Crear una sección adicional estructurada para añadir enlaces directos a redes sociales (LinkedIn, GitHub, Instagram, etc.).
