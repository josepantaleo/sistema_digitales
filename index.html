Sistema

El concepto de sistema se refiere a un conjunto de elementos que están relacionados entre sí y trabajan juntos para cumplir una función o alcanzar un objetivo.

Sistema Digital

Un sistema digital es un conjunto de dispositivos electrónicos que procesan, almacenan o transmiten información usando señales digitales representadas por 0 y 1.

Características principales

  • Utiliza señales binarias (0 y 1).
  • La información se procesa mediante circuitos lógicos.
  • Es más preciso y resistente al ruido que los sistemas analógicos.

Componentes básicos

  • Entradas: reciben datos (teclado, sensores).
  • Procesamiento: puertas lógicas y circuitos digitales.
  • Salidas: muestran o envían el resultado (pantalla, impresora).

Ejemplos

  • Computadoras
  • Teléfonos celulares
  • Calculadoras
  • Relojes digitales
  • Consolas de videojuegos
✔ Un sistema digital trabaja con información en forma de bits (0 y 1).

Sistema Analógico

Un sistema analógico representa y procesa información mediante señales continuas.

Características

  • Utiliza señales continuas.
  • Los valores cambian de forma progresiva.
  • Es más sensible al ruido.

Ejemplos

  • Reloj con agujas
  • Radio analógica
  • Termómetro de mercurio
✔ Un sistema analógico usa señales continuas.

BIT

Un bit (binary digit) es la unidad más pequeña de información en informática.

Características

  • Solo puede tener dos valores: 0 o 1.
  • Representa estados como encendido/apagado.

Relación con otras unidades

  • 8 bits = 1 byte
  • Los bytes representan letras, números y símbolos.
✔ Un bit es la unidad básica de información digital.

Sistema Binario

El sistema binario utiliza solo dos números: 0 y 1.

Características

  • Su base es 2.
  • Cada posición representa una potencia de 2.
  • Es el sistema utilizado por las computadoras.
Ejemplo: 1011 = 8 + 0 + 2 + 1 = 11

Conversiones

Decimal → Binario

Dividir entre 2 y tomar los restos.

Binario → Decimal

Sumar potencias de 2 según cada bit.

Hardware

Concepto: El hardware se refiere a todas las partes físicas de una computadora, es decir, los componentes tangibles que puedes ver y tocar. Incluye desde el procesador, la memoria y el disco duro, hasta la placa base, la tarjeta gráfica, los periféricos como teclado y monitor, y dispositivos de almacenamiento o red.

Hardware de PC

1. Procesador (CPU)

Función: Ejecuta instrucciones de programas y controla el funcionamiento de todo el PC.

Características importantes:

  • Número de núcleos: Más núcleos = mejor rendimiento en multitarea (ej: 4, 6, 8, 12).
  • Hilos (Threads): Permiten procesar varias tareas simultáneamente.
  • Frecuencia (GHz): Velocidad de operación; más GHz = más rápido en tareas individuales.
  • Caché: Memoria interna rápida para acelerar procesos.

Tipos populares: Intel Core (i3, i5, i7, i9), AMD Ryzen (3, 5, 7, 9).

2. Placa base (Motherboard)

Función: Une todos los componentes y permite la comunicación entre ellos.

Factores a considerar:

  • Socket de CPU: Debe coincidir con tu procesador.
  • Ranuras de RAM: Determina la cantidad y tipo de memoria que puedes instalar.
  • Puertos de expansión: Para tarjetas gráficas, de sonido, capturadoras, etc.
  • Chipset: Controla las capacidades de la placa (overclocking, soporte de RAM rápida, etc.).

Tipos comunes: ATX, Micro-ATX, Mini-ITX.

3. Memoria RAM

Función: Almacena temporalmente datos para que la CPU los use rápido.

  • Tipos: DDR3, DDR4, DDR5 (DDR5 es la más nueva y rápida).
  • Capacidad recomendada:
    • 8GB → Uso básico
    • 16GB → Juegos y productividad
    • 32GB+ → Edición de video, diseño 3D, multitarea pesada
  • Velocidad: MHz; más alta = mayor velocidad de transferencia de datos.

4. Almacenamiento

  • HDD: Más económico, gran capacidad (1TB+), lento.
  • SSD: Más rápido, arranque y carga de programas veloz. Capacidades: 256GB, 512GB, 1TB.
  • NVMe / M.2 SSD: Mucho más rápido que SSD normal, se conecta directamente a la placa.
Recomendación: Combinar SSD (SO y programas) + HDD (archivos grandes).

5. Tarjeta gráfica (GPU)

Función: Procesa gráficos, video y cálculos paralelos (GPU computing).

  • Tipos: Integrada (para tareas básicas) o dedicada (juegos, edición, diseño 3D).
  • Ejemplos: NVIDIA GeForce RTX 3060, 4070; AMD Radeon RX 6600, 7900.
  • VRAM: Memoria dedicada; 4GB mínimo para juegos básicos, 8GB+ para juegos modernos y edición.

6. Fuente de alimentación (PSU)

  • Potencia: 450W – 1000W según configuración.
  • Certificación: 80 PLUS (eficiencia energética).
Nunca escatimes en PSU; una mala fuente puede dañar tus componentes.

7. Gabinete

  • Tamaño: ATX, Micro-ATX, Mini-ITX.
  • Ventilación: Crucial para mantener temperaturas bajas.
  • Extras: Paneles de vidrio, iluminación RGB, filtros de polvo.

8. Periféricos

  • Monitor: Resolución (Full HD, 2K, 4K), tasa de refresco (60Hz, 144Hz, 240Hz), panel (IPS, TN, VA).
  • Teclado y ratón: Mecánico vs membrana, DPI ajustable para el ratón.
  • Audio: Auriculares, altavoces, micrófono.
  • Otros: Webcam, impresora, joystick, tablet gráfica.

9. Sistema de refrigeración

  • Ventiladores: Mantienen aire circulando.
  • Disipadores de CPU/GPU: Enfriamiento directo de los chips.
  • Líquido (water cooling): Opcional, mejor rendimiento térmico, más caro.

10. Dispositivos de red

  • Tarjeta Wi-Fi o Ethernet.
  • Importante para conexión rápida y estable.
